# FAFU 机械臂站控 · 使用说明

本文面向**操作员**与**交付/维护人员**，说明如何在 Windows 电脑上安装、启动和使用本软件。技术实现细节见 [`SPEC.md`](SPEC.md)。

---

## 1. 软件是什么

FAFU 机械臂站控是运行在**客户 PC 本机**的控制软件：

- 通过 **USB** 直连机械臂调试板
- 打开后进入**机械臂控制页**：3D 参考臂、关节/笛卡尔滑条、作业相机、急停等
- 以**独立应用窗口**运行（推荐），也可在浏览器访问 `http://127.0.0.1:9400/`
- 无真机时可在同一页面切换到**仿真臂**，用于熟悉界面和轨迹

---

## 2. 电脑与硬件要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10 / 11 64 位 |
| 客户软件 | 使用便携包时**不必**安装系统 Python |
| 开发机 | 未打包时需要本机 **Python 3.10**（官方 `fafu_motor` 为 cp310） |
| 机械臂连接 | USB 线接到**运行本软件的这台电脑** |
| 作业相机 | USB 接到同一台电脑（交付相机为 Intel RealSense D405）。软件自动识别，不会用笔记本盖上的内置摄像头 |
| SDK | 便携包应已内置；源码运行时需 [fafu_arm_sdk](https://github.com/FAFU-Robotics/fafu_arm_sdk) |
| 窗口 | Windows 自带 Edge / WebView2（Win10/11 通常已有） |
| 可选 | USB-C 笔记本建议可靠转接 |

## 3. 安装步骤

### 3.1 客户：安装便携包（推荐，不影响系统 Python）

在**开发机**先打包（只需做一次）：

```bat
powershell -ExecutionPolicy Bypass -File packaging\windows\build_portable.ps1
```

或双击 `packaging\windows\build_portable.bat`。得到 `dist\FAFUArmStation\`。

把该文件夹（可打 zip）拷到客户电脑后：

1. **插上机械臂 USB**（插在这台电脑上）
2. **插上作业相机 USB**（RealSense D405；不要依赖笔记本内置摄像头）
3. 双击 **`FAFUArmStation.exe`** 或 **`启动真机.bat`**

第一次会把软件拷到 `%LOCALAPPDATA%\FAFUArmStation`（只给本软件用，不改系统 PATH），建桌面快捷方式，并打开控制页。USB 连上后会自动 Connect 并使能（电机保持当前姿态，不会自己甩臂）。

以后：点桌面 **FAFUArmStation** 即可，不必再解压、不必再点 Connect / 使能。

更新：发新的 zip，再双击其中的 `FAFUArmStation.exe`，会覆盖用户目录里的副本。

**隔离保证：**

- 不会安装「系统里的 Python」
- 不会用 `setx` 或改注册表去写 PATH
- 不会把包装进客户的 `pip --user`
- 卸载：运行安装目录中的 `Uninstall.bat`，或删除 `%LOCALAPPDATA%\FAFUArmStation` 与桌面快捷方式

无法关进软件目录的部分：USB 串口驱动、系统已有的 Edge/WebView2。

### 3.2 开发机：从源码运行

将整个 `robot_station` 文件夹放在开发电脑上。安装 [Python 3.10](https://www.python.org/downloads/release/python-31011/)，并把 `fafu_arm_sdk` 放到仓库旁或设置 `FAFU_ARM_SDK`。

`启动真机.bat` 在存在 `runtime\python310\python.exe` 时会**优先用私有运行时**；否则才用 `%LocalAppData%\Programs\Python\Python310\python.exe`（这是开发机自己的 Python，不要把这一步当成客户交付）。

依赖（仅开发机、且未走便携包时）：

```bat
%LocalAppData%\Programs\Python\Python310\python.exe -m pip install websockets PyYAML pywebview numpy pyrealsense2
```

### 3.3 配置文件（可选）

首次从源码使用可复制示例配置：

```bat
copy configs\station.example.yaml configs\station.yaml
```

默认 `configs\station.yaml` 中 `arm: mock`、`arm_allow_motion: false`，适合安全试界面。真机请用 `启动真机.bat`，它会覆盖为真机模式。

## 4. 启动方式

### 4.1 推荐：客户便携包 / 真机

- 已安装便携包：双击桌面 **FAFUArmStation**，或 `%LOCALAPPDATA%\FAFUArmStation\FAFUArmStation.exe`
- 源码开发机：双击仓库根目录 `启动真机.bat`

该启动会：

- 设置 `STATION_ALLOW_LIVE_ARM=1`（允许打开真机 USB 串口）
- 便携包使用 **私有** Python 3.10（`STATION_PORTABLE=1`），不改系统 PATH
- 以 **fafu + allow-motion** 模式拉起站控
- USB 连上后自动 Connect 并使能
- 打开独立应用窗口

### 4.2 桌面快捷方式

- 便携包：第一次双击 `FAFUArmStation.exe` 就会创建桌面快捷方式。
- 源码开发机：双击仓库根目录 `启动真机.bat`。

### 4.3 命令行启动

**独立窗口（推荐）：**

```bat
set STATION_ALLOW_LIVE_ARM=1
py -3.10 station_desktop.py
```

**仅命令行 / 服务：**

```bat
py -3.10 run_station.py
```

**无真机、只看界面：**

```bat
py -3.10 run_station.py --arm sim
```

**常用参数：**

| 参数 | 说明 |
|------|------|
| `--arm mock\|sim\|fafu\|auto` | 臂后端：假臂 / 仿真 / 真机 / 自动 |
| `--allow-motion` | 允许真机下发运动（还须 `STATION_ALLOW_LIVE_ARM=1`） |
| `--replace` | 结束占用 9400/9470 端口的旧站控后重启 |
| `--no-browser` | 不自动打开浏览器 |
| `--config 路径` | 指定 yaml 配置 |

### 4.4 访问地址

| 地址 | 用途 |
|------|------|
| `http://127.0.0.1:9400/` | 机械臂控制页（默认） |
| `http://127.0.0.1:9400/lab` | 本机状态页（进程是否在线） |

## 5. 真机与仿真的区别

软件有两道**安全闸门**，真机运动必须同时满足：

1. **串口许可**：环境变量 `STATION_ALLOW_LIVE_ARM=1`（`启动真机.bat` 已设置）
2. **运动许可**：`arm_allow_motion: true` 或启动参数 `--allow-motion`

| 模式 | 是否开 USB | 网页操作是否动真臂 | 典型用途 |
|------|------------|-------------------|----------|
| mock（默认配置） | 否 | 否 | 假数据演示 |
| sim（仿真臂） | 否 | 否（只驱动仿真） | 练界面、轨迹 |
| fafu（真机 USB） | 是 | 是（启动真机后自动 Connect+使能） | 实际控制 |

**页面切换：** 右侧 **臂源** 可在「真机 USB」与「仿真臂」之间切换，无需重启。切回真机**不会自动使能**，需手动 Connect / 使能。

**USB 端口：** 配置中 `arm_port` 留空时，SDK 使用 `port=auto` 自动选择 COM 口。也可在 `configs/station.yaml` 中指定，例如 `arm_port: COM3`。

## 6. 日常操作流程（真机）

建议按以下顺序操作：

1. **接线**：机械臂 USB 接到本机
2. **清场**：工作空间内无障碍物
3. **启动**：双击 `FAFUArmStation.exe` / `启动真机.bat` / 桌面快捷方式
4. **控臂**：窗口打开后可用键盘，或拖滑条后点「发送位置」。要边拖边动，先勾选「实时跟随」（不会因拖滑条自动勾上）。切过仿真再切回真机时，需再点「使能」。
5. **结束**：关闭窗口即可（会结束站控）。需要卸力时再点「去使能」。

### 只读探测（不动臂、不使能）

用于确认 SDK 与 USB 是否正常：

```bat
set STATION_ALLOW_LIVE_ARM=1
set FAFU_ARM_SDK=D:\fafu_arm_sdk
py -3.10 -m robot_station.adapters.fafu_arm
```

会列出可能的调试板并尝试只读连接，**不会使能、不会下发运动**。

## 7. 界面说明

### 7.1 顶栏

- **连接 / 指令 Hz / RTT**：连接表示机械臂 USB 或仿真植物是否在线（不是网页套接字）。未插真机或总线无应答时应为「未连接」，不要显示「真机已连接」。
- **假臂 · 假相机**：当前臂源 / 作业相机是否为 mock。识别到 RealSense 后显示「真相机」。
- **急停 ESTOP / 解除急停**：软件急停锁存；急停后电机**保持当前姿态**（不是断电卸力）

### 7.2 机械臂页布局

- **左侧**：关节/笛卡尔滑条、路点（稀疏关键帧）、示教轨迹（连续录制/回放）、速度。关节滑条未勾选「实时跟随」时只改目标，点「发送位置」才动臂。
- **中间**：3D 参考臂（SDK CAD，分段浅灰上色；夹爪开合有行程，不是瞬移；拖拽旋转、滚轮缩放、双击重新框选）、作业相机（启动时自动认 USB；运行中插入也会自动出画，不必重启；优先 RealSense D405，跳过笔记本内置摄像头；未接时显示假画面并写明原因）。若画面一直是假彩条，请看叠加层原因，或在 Windows「设置 → 隐私和安全性 → 相机」中允许桌面应用访问相机。
- **右侧**：
  - **臂源**：真机 USB / 仿真臂
  - **Connection**：Connect / Disconnect、使能 / 去使能。当前态会亮起；按下后到应答前显示「正在连接 / 断开 / 使能…」，说明写在按钮下方。
  - **CONTROL MODE**：Position / Gravity / Gra+Fri / Impedance
  - **夹爪**：开/关（当前开合会亮起）、角度、夹持力矩

### 7.3 控制模式简述

| 模式 | 真机行为 | 仿真行为 |
|------|----------|----------|
| Position | `move_j` / `servo_j` 位置控制 | 滑条 + 插补 |
| Gravity | 重力补偿，可手拖（无 pinocchio 时用站控 G(q)） | 滑条示教 |
| Gra+Fri | 重力 + 摩擦补偿 | 同 Gravity 示教 |
| Impedance | 柔顺保持进入时的姿态 | 较慢位置跟随 |

真机 Gravity / Gra+Fri / Impedance 不依赖 pinocchio。切到仿真臂后这三档仍是滑条示教，不是力矩环。真机零力矩需要 **J1–J6 都在线**；夹爪（M7）离线仍可补偿。臂关节缺轴时请用 Position 控制在线轴，不要进重力。

### 7.4 示教轨迹（连续录制 / 回放）

与「路点」不是同一件事：路点是网页里点几下记下的稀疏姿态；示教轨迹是运动进程按 100 Hz 写到磁盘的连续曲线。

1. 示教面板默认是 **拖臂录制**（与 SDK `test_fafu_motion_interactive` 的 [t] 示教一致）：点「开始录制」会切入 **Gra+Fri / Gravity**，先扶稳再徒手拖。仿真没有力矩环，用滑条示教。若要键盘/跟随记录，切到 **软件录制**（留在 Position）。
2. 页面显示帧数。点「停止录制」后文件在 `%LOCALAPPDATA%\FAFUArmStation\recordings\`（开发可用环境变量 `STATION_RECORDINGS_DIR`）。拖臂录制结束会回到 Position 保持。
3. 选文件，点「回放」。先**慢速**走到轨迹起点并停稳，再按录制时的时间戳 `servo_j`。回放倍率 0.5–1.0。夹爪离线时关节仍回放，夹爪指令会跳过。
4. 「删除文件」只删本机 recordings 里选中的 jsonl。急停会停止录制并保留已写下的文件。不要用路点「运行轨迹」来还原拖臂时序。

## 9. 配置文件说明

编辑 `configs/station.yaml`（可参考 `configs/station.example.yaml`）：

```yaml
http_port: 9400          # 网页端口
motion_port: 9470        # 运动进程端口（一般勿改）
arm: mock                # mock | sim | fafu | auto
arm_allow_motion: false  # 是否允许真机运动
arm_sdk: ""              # 空=自动查找 fafu_arm_sdk
arm_port: ""             # 空=auto 自动选 COM 口
arm_speed_deg_s: 40      # 默认速度
```

**注意：** 即使配置了 `arm: fafu`，未设置 `STATION_ALLOW_LIVE_ARM=1` 时启动仍会被改为 `sim`，不会打开 USB。

## 10. 交付给其他电脑

**推荐：便携包**（详见 [`packaging/windows/README.md`](../packaging/windows/README.md)）

1. 开发机运行 `packaging\windows\build_portable.bat`
2. 把 `dist\FAFUArmStation` 整个文件夹发给客户（可打 zip）
3. 客户把机械臂 USB 接到**对方电脑**，双击 `FAFUArmStation.exe`
4. 第一次会装到用户目录并打开页面（已自动 Connect + 使能）；以后点桌面快捷方式
5. 无真机可在页面切 **仿真臂**

对方**不必**再安装 Python 3.10，也**不要**勾选 Add to PATH。

打包时若找不到 `fafu_arm_sdk`，仿真仍可用；真机需在开发机带上 SDK 后重新打包。

USB 调试板驱动仍是系统级的：若 Windows 认不出 COM 口，需要按厂商说明安装驱动（无法放进私有 Python 目录）。

源码拷贝交付（不推荐给最终客户）：仍按旧步骤装 Python 3.10。客户交付请用 `packaging\windows\build_portable.ps1` 打出的便携包。

## 11. 常见问题

### 页面能开，但动不了真臂

- 顶部是否显示「未允许真机串口」→ 用 `FAFUArmStation.exe` / `启动真机.bat` 启动
- 臂源是否为 **仿真臂** → 切到 **真机 USB** 后再点「使能」（页面切换不自动使能）
- USB 是否在启动前已插上（启动后才插需点 Connect / 使能，或重启）
- `configs/station.yaml` 中 `arm_allow_motion` 是否为 `false` 且未加 `--allow-motion`

### 部分电机离线（夹爪或某轴没装）

- 交付时可以不装夹爪或个别电机。顶部会显示「部分轴离线 n/m」，在线轴仍可 Connect、使能、关节/键盘控制。
- 不要因为夹爪离线就放弃整臂。夹爪按钮会提示离线，其余轴照常。
- 若以前版本在缺轴时「使能失败」，重启运动进程后再点「使能」。

### 提示找不到 fafu_arm_sdk

- 将 SDK 放到仓库旁，或设置 `FAFU_ARM_SDK=SDK根目录`
- 确认存在 `fafu_robot_python\fafu_robot_controller.py`

### 提示 fafu_motor 载不入 / cp310

- 必须使用 **Python 3.10** 启动，不要用 3.11/3.12
- 检查 SDK 内是否有 `fafu_motor.cp310-win_amd64.pyd`

### 真机连接失败，自动变成仿真

- USB 是否插在本机；设备管理器是否有 COM 口
- 是否有其他程序占用同一串口（官方工具、旧进程）
- 运行只读探测命令查看 `debug_boards` 列表
- 可在配置中手动指定 `arm_port: COMx`

### 9400 端口已被占用

- 站控已在运行：直接打开 `http://127.0.0.1:9400/`，勿重复启动。真机运动还在时，再开窗口会复用，不会杀掉机械臂。
- 页面顶栏变「未连接」但臂还在 hold：不要整站 `--replace`。关窗口再开、或点离线页「重新连接」，会只补网页。
- 需要整站重启（确认机械臂已停下）：使用 `--replace` 或结束 9470 后再启

### 独立窗口打不开

- 便携包：用 `build_portable.ps1` 重新打包，确认私有环境里有 pywebview
- 开发机：`pip install pywebview`（仅本机开发用的 Python）
- Windows 需 Edge WebView2（Win10/11 通常已有）
- 查看日志：`%TEMP%\fafu-station-app.log`

### 重力 / 阻抗模式不可用

- 真机需要力矩下发接口（`apply_compensation_torque`）。无 pinocchio 时站控用 URDF 质量/质心算 `G(q)`，经 MIT 下发。
- **J1–J6 必须都在线**才能进重力/阻抗；夹爪没装不影响。某一臂关节离线时按钮会不可用。
- 切到「仿真臂」后仍可进入 Gravity 做滑条示教（不是真力矩环）。
- 笛卡尔键盘在缺 pinocchio 时仍可用站控内置 IK（100 Hz，不用 Trac-IK）。开发机可 `py -3.10 -m pip install pytracik`，仅笛卡尔「发送位置」在旧 IK 无解时再试一次 Trac-IK。重力补偿与 pytracik 无关。

## 12. 安全须知

- **急停**为本站软件锁存，保持当前姿态；拔 USB 也可立即停止通信
- 使能前务必清空工作空间，确认周围无人
- 首次真机操作建议低速度，先关节小幅运动
- 不要在 SERVOING / 实时跟随时强行切换使能状态
- 复位（`H`）按**当前姿态**受控回零：只在会探桌时略抬肘，不故意往上伸直扫顶；沿路点连续插补，中间不停顿
- 仿真模式下网页动作**不会**传到真机，可用于培训；切真机前再次确认臂源与使能状态

## 14. 关于打包成独立软件

当前**客户推荐形态**是「安装目录 + 私有 Python」，不是单文件绿色 exe。

- 打包：`packaging/windows/build_portable.ps1` → `dist/FAFUArmStation/`
- 启动器：`FAFUArmStation.exe` 只启动**目录内**的 `runtime\python310`，并设置进程内 `STATION_PORTABLE=1`
- 双进程（网页 + 运动）都使用同一份私有 `python.exe`（`sys.executable`）
- 未采用 PyInstaller 单文件：原生 `fafu_motor.pyd` 与双进程更适合目录布局

不要把 `runtime\python310` 加入客户系统 PATH。
