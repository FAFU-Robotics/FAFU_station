# 程序与作业工作台

站控使用单行导航，默认打开手动控制。作业入口是紧凑的分段按钮：左侧显示最近使用的页面并直接进入，右侧独立箭头打开页面菜单，中间有分隔线。默认选择程序，菜单可切换程序、路点与示教轨迹，支持方向键和回车选择；点击外部关闭菜单。各页面共用设备连接，切页不会重新连接或使能。

顶栏的日间 / 夜间按钮可切换外观。日间使用浅灰背景、白色卡片和蓝色强调色，表单、提示、菜单、3D 网格与轨迹曲线同步适配；状态灯和急停保留各自的颜色含义。首次使用默认夜间，选择保存在本机浏览器中，刷新后恢复，也同步到同源的其它窗口。切换主题不会重连设备、发送运动指令或中断当前任务。

字号按信息层级统一：桌面页标题 26px（窄屏 24px）、卡片标题 16px、正文与常用操作 14px、说明与标签 13px，次要元数据通常为 12px。卡片采用统一的留白和列间距；导航、提示条与内容区域对齐。手动控制的键盘说明位于三维视图下方，减少左侧关节面板的纵向堆叠；桌面保留三栏，窄屏按可用宽度重排。

正文、按钮和表单统一使用本地随包提供的 Noto Sans SC，采用 400–700 可变字重；中文与拉丁字符使用同一套字形，数值使用等宽数字。该字体来自 [Google Fonts 官方仓库](https://github.com/google/fonts/tree/main/ofl/notosanssc)，以 SIL OFL 1.1 分发，许可证随字体提供；加载不依赖外部网络，缺失字形回退到系统中文 UI 字体。辅助文字与禁用按钮不再依靠整体透明度变淡，日间主要、辅助及禁用文字色对分别按 [WCAG 普通文字 4.5:1 对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)校验。

## 连接检查

控制界面不再显示相机、相机显隐按钮或相机真假状态，也不建立视频 WebSocket。顶部五项状态用于判断连接是否有效、是否使能、是否急停、当前任务以及通信延迟。反馈过期时显示未知/超时，避免保留旧的就绪状态。

连接入口统一为「选择连接方式 → 选择串口或本机仿真 → 连接 → 检查反馈 → 单独使能」。串口列表包含本机所有已枚举端口；也可手动输入 `COM3`、`/dev/ttyUSB0` 或 `/dev/serial/by-id/...`。当前使用 FAFU 驱动。连接期间及已连接时锁定目标选择，切换前必须先断开。串口与本机仿真各自独立，连接失败、拔线、插入 USB 或重新枚举不会互相切换；指定端口不存在时不尝试其它端口。旧配置使用自动枚举时，只允许唯一候选板，多个候选必须手动选择。

真机默认等待手动连接，启动时不打开串口、不使能。明确配置 `arm_connect_on_start: true` 可连接配置目标，但仍需手动使能。仿真沿用配置中的初始连接，连接后同样需要使能才能运动。断开会停止手动输入并结束当前连接，保留真机支撑状态，不等同于关闭电机力矩；录制、回放、程序执行时需先停止任务再断开。重连从新连接的实测姿态开始，不复制仿真的关节目标、夹爪指令或运行状态。

每次启动、连接、断开或异常掉线都会更新连接会话标识。浏览器在指令创建时附带该标识，连接变化前排队的运动、使能或程序指令会被拒绝；急停始终可用。端口打开和关闭在连接操作中串行执行，运动循环继续发布离线/连接中状态。新版前端检测到旧运动服务时禁用连接入口并提示重启，避免只刷新网页后误用旧的自动切换逻辑。

连接卡统一显示连接状态。未连接时，所选方式和端口标为「待连接」，不会沿用上一次连接的仿真说明、使能、夹爪或控制模式反馈；状态超时也不显示旧反馈。手动输入端口后可点击「连接串口」或按回车，刷新设备列表会保留手输内容。

顶栏、连接卡、总览及手动控制共用连接阶段、控制通道和反馈时效的判断。仿真或串口断开时，顶栏显示「无活动设备」；通信中断或反馈超时则显示「设备状态未知」，电机表、实测角度和位姿不再沿用旧值。实时跟随期间也持续更新这些状态；掉线或连接会话变化会取消本窗口的跟随输入，恢复通信后需重新手动开启。迟到的旧位姿帧不能覆盖较新的状态。

是否允许访问串口由启动进程的 `STATION_ALLOW_LIVE_ARM` 决定，与所选连接方式独立。未开放串口访问的预览进程仍可连接本机仿真；尝试连接串口会说明原因和「启动真机」入口，不发送连接指令。通过真机启动器打开的站控在同一界面内支持串口与仿真，切换前仍需先断开。

控制通道断开时，运动与使能等指令立即失败，不在恢复连接后补发；急停保留补发行为。使能标签始终反映电机反馈。如果新连接的电机已处于使能状态，标签显示「已使能」，按钮显示「确认使能」；确认后以当前实测姿态接管控制，不追赶断开前或仿真中的旧目标。

连接模型参考 [URSim 独立控制器端点](https://www.universal-robots.com/articles/ur/interface-communication/connecting-to-client-interfaces-within-ursim/)和 [RoboDK 的明确端口与 Connect 操作](https://robodk.com/doc/en/Robot-Calibration-LaserTracker-Connect-robot.html)，结合本站串口 SDK 实现。

「USB / 串口设备」直接显示本机串口及 SDK 识别的候选调试板，包含设备描述与 VID/PID。点击「刷新设备」重新枚举，仿真模式也会显示真实的电脑串口。未识别到设备时显示空状态与接线、供电、驱动检查提示。枚举不会打开串口、检测占用、探测电机或自动连接/使能；候选板不代表机械臂已连接。服务地址、WebSocket、运动进程通道及 SDK 等内部信息收进默认折叠的「技术诊断」。

顶栏在「已连接」后单独显示使能状态标签：已使能亮绿灯，未使能亮红灯，状态未知为灰灯。标签依据设备反馈更新，等待操作完成时继续显示当前已确认的状态。「使能 / 去使能」共用一个简洁的操作按钮，只显示动作文字，操作处理中显示等待提示并禁用，避免重复点击。设备离线、反馈超时、急停锁存或程序占用时不可用。去使能前会停止当前窗口的手动跟随与按键输入。顶栏不重复显示当前页、视频频率和 IP。

顶栏只保留一个「快捷键」入口，点击展开完整说明，再次点击或点击外部收起。说明面板始终位于顶栏下方，窄屏时在面板内滚动；按钮和面板获得焦点时不触发手动运动快捷键，Esc 急停仍全局生效。

普通操作使用随内容宽度收缩的轻量浮动提示，以小图标区分进度、成功与失败，操作进度在同一张卡片中更新为结果。成功提示约 3.5 秒消失，错误约 7 秒消失，也可手动关闭；重复消息不延长显示时间，持续相同错误关闭后不会立即重弹。所有页面统一在窗口上方居中显示，位于顶栏、导航与任务条下方，不再根据空白区域向左右移动；不同长度、类型的消息使用相同的中心和顶部锚点。提示层低于顶栏与底部执行栏，鼠标停留或关闭按钮获得焦点时暂停自动消失，卡片不会让点击穿透到后方控件；显示提示不改变页面布局或抢走焦点。急停锁存与仿真模式继续使用对应的状态横幅，较长错误在原功能区域保留完整提示。

去使能会结束正在录制的轨迹、回放、重力与伺服控制，在伺服所属线程调用 SDK `disable()` 并验证 STOP 模式。**这会取消电机保持力矩，需先扶稳机械臂或让它处于安全支撑姿态。** ACK 表示请求已受理，按钮须等设备反馈确认后切回「使能」；未进入 STOP 或无反馈会报错。普通保位、切页、断连、关闭连接与解除急停不会自动重新使能。再次使能以当前实测姿态作为目标，避免追赶去使能前的旧位置。旧版运动进程需要先重启才能使用真正去使能。

信息组织参考 [Foxglove 的诊断状态汇总](https://foxglove.dev/blog/using-ros-diagnostics-in-robotics-operations) 和 [UR Client Library 的连接/服务准备流程](https://github.com/UniversalRobots/Universal_Robots_Client_Library/blob/master/doc/setup/robot_setup.rst)，按本站已有反馈与接口取舍，保留现有配色和卡片风格。

## 路点

在手动控制页把机械臂移动到目标姿态，进入路点页点击「记录当前位置」。采集的是机械臂反馈位置，自动命名并选中新路点，不会触发运动。

「手动添加」自动命名并打开六个空白角度框，不预填滑条值，也不默认使用零值。右上角显示已填写数量。可以用 Tab / Enter 切换输入框；只填写一部分时保留为草稿，不保存、不结束编辑。六轴全部填写为有效且在限位内的角度，并结束当前输入（Tab、Enter 或移开焦点）后，自动添加并保存一次。无需「完成添加」或「保存」按钮。零度需要明确输入 0，留空不能当作零。「取消添加」使用红色描边；未修改时直接取消，修改未提交时需要确认。未完成的草稿不能执行。

左侧列表只负责选择路点，右侧编辑所选路点的名称和六轴角度。结束输入（移开焦点或按 Enter）后自动保存，保存状态显示在编辑区右上角；保存失败会提示且保留待保存修改。名称不能重复，角度不能超出已知的关节限位。列表下方提供 JSON 导入导出和清空列表。删除和清空使用红色描边按钮，确认后才删除。

角度及速度只接受普通十进制数字，支持负角度及小数，拒绝科学计数法、非数值、空值和越界值，粘贴同样校验。程序参数中的等待时间和循环次数不再把空值视为零，循环次数必须为整数。手动控制的关节目标也不会把空白当作零发送。

笛卡尔控制默认只编辑目标：拖动、松手或修改 XYZ、RPY 数值都不会自动运动，点击「发送位置」后才按设定速度移动。目标不会随反馈刷新；「填入当前位姿」将当前 XYZ、RPY 复制到目标框，便于从当前位置微调，本身不启动运动。与关节控制共用「实时跟随」开关，默认关闭，切换控制空间或离开手动页会关闭。开启笛卡尔跟随后先采用当前位姿，之后的拖动才连续下发；每秒最多 10 次，同时只保留一个等待应答的 IK 请求，新拖动合并为最新目标。关闭或切页会取消待发送更新，并停止属于当前窗口的笛卡尔跟随运动。旧服务未声明支持时禁用此开关，重启更新后的站控后启用。

实时 XYZ（m）与 RPY（°）集中显示在 3D 参考臂下方，并标明基坐标系；左侧仅显示目标，右侧末端状态不再重复位姿。实时值收拢为固定宽度的紧凑双行，单位放在行末。位置与 3D 坐标轴使用 X 红、Y 绿、Z 蓝；姿态使用 R 紫、P 橙、Y 青，目标框数值保持普通文字颜色。姿态标签及快捷键统一使用 R、P、Y。

底部保持可见的执行栏与列表共用同一个目标，设置速度后点击「到此位置」，只前往所选位置。选择和编辑本身不会触发运动。状态先等待后端确认，再显示正在前往；实测关节位置稳定到位后才显示已到达，停止、断连或执行失败不会显示已到达。

页面不再提供运行全部路点、重录实测和每点时长；单点运动按设置速度插补，旧文件的时长字段保留兼容但不参与该运动。程序中的 MoveJ 使用该步骤自己的速度，多步运动在程序页组织。

## 程序树

左侧统一管理当前程序和程序库，页面顶部不再重复放置文件操作栏。侧栏上部显示正在编辑的名称、保存状态，以及保存、另存副本、删除；下部为可搜索的紧凑文件列表。新建草稿可直接填写名称；已保存程序的名称只读，另存副本时单独填写新名称，不会因误改名称而另存或覆盖其他程序。切换程序或新建前会检查未保存修改，删除操作针对当前打开的已保存程序，保存失败保留草稿并在侧栏显示原因。

中间编辑程序树，右侧编辑参数。直接点击树中需要位置的「＋」再选择动作，不再选择额外的添加位置。重复块内显示「重复执行」，条件块分为「条件成立时」和「否则」两个独立区域，各自有内部添加入口；「重复结束」或「判断结束」之后的添加入口位于外层。顶部「在程序末尾添加」始终追加到最外层。已有步骤可拖到任意「＋」处调整顺序、移入或移出分支，重复和条件可整块移动，禁止拖入自己的内部。取消动作选择不会修改程序，新增步骤只滚动树内位置，不跳动整个页面。上移、下移、复制和删除仅在有可操作的选中步骤时可用，撤销仅在有编辑历史时可用，保存不会清空当前编辑历史。

右侧「位置与轨迹预览」只在选中有效 MoveJ 目标或已指定文件的轨迹调用时出现；夹爪、等待、注释、重复和条件节点不显示 3D，也不为它们创建或调度预览。MoveJ 显示目标姿态，参数修改即时联动；轨迹调用显示起点及末端路径。可切换实测姿态对照，面板可折叠。这里只预览目标和路径，不执行动作，也不代表完整程序仿真。步骤预览与手动控制、轨迹预览共用 WebGL 渲染器和 CAD 缓存；收起或切页停止绘制，过期的轨迹查询响应不能重新打开或覆盖预览。

本轮交互参考（2026-10-30）：[PolyScope X 的分支内与分支后添加入口](https://www.universal-robots.com/manuals/EN/HTML/SW10_13/Content/prod-usr-man/software/PolyScopeX/polyx-basic/polyx-else_if.htm)、[RoboDK 的指令相邻插入规则](https://robodk.com/doc/en/Robot-Programs-Program-Instructions.html)。本站采用可见的结构边界和就地添加入口，让添加位置直接对应执行层级。

MoveJ 可以引用命名路点，也可以直接填写六个关节角度。夹爪动作设置打开/闭合和原始力矩上限。Nm 估算依据所连接电机型号及 SDK 力矩表；它不是指尖夹持力的测量值。

第一版支持 MoveJ、夹爪、等待、有限次数重复、状态条件、示教轨迹回放和注释。MoveJ 是关节空间运动；末端直线 MoveL 尚未接入。

## FAFU 简化脚本

程序树和脚本使用相同的指令集。脚本切回程序树前点击「检查并应用到程序树」，或直接切换，编辑器会执行同样的检查。脚本是受限指令数据，不执行 Python 程序，也不启动独立 SDK 进程。

```python
comment("取放动作")
movej("取料点", speed=20)
gripper_close(effort=120)
sleep(0.5)
movej("放料点", speed=20)
gripper_open(effort=120)

for _ in range(3):
    if gripper_is_open():
        gripper_close()
    else:
        gripper_open()

replay("traj_20261029_120000.jsonl", rate=0.8, speed=20)
```

角度为 °，MoveJ 和走近轨迹起点的速度为 °/s，等待为秒。`movej([0,40,40,0,0,0], speed=20)` 支持直接写角度。夹爪 `effort` 范围为 50–800 raw，默认 300。速度范围 5–80°/s，回放倍率 0.5–1.0。

条件支持 `gripper_is_open()`、`gripper_is_closed()`、`robot_is_enabled()` 和 `robot_is_connected()`。夹爪条件表示开合状态，不表示已确认抓到物体。失去连接/使能会优先停止程序。循环变量仅用于计数，不支持变量表达式、import、任意函数、文件或网络访问。

程序最多 256 个节点、8 层嵌套；展开后最多 10000 步。参数、引用路点、轨迹文件及关节限位会在开始运动前检查。

## 执行

开始前连接并使能机械臂，切回 Position，并停止正在进行的示教录制或其它运动。运行倍率的有效速度下限为 5°/s。

- **运行**：使用启动时的程序与路点快照，按顺序等待每个动作完成。MoveJ 到位依据反馈位置，接收指令的 ACK 不代表运动完成。
- **暂停**：中止当前动作并保持实测姿态；继续时重新执行当前步骤。等待会重新计时；轨迹回放会重新走近起点再播放。
- **单步**：完成一个动作后暂停；最后一个动作完成后结束程序。
- **停止**：取消后续步骤，结束当前路点/回放，并保持当前位置。
- **急停**：保持站控原有刹车和锁存语义；程序随之终止，不自动续跑。

程序运行或暂停期间占用运动接口，手动运动、复位、切模式和切臂源会被拒绝。切换导航不影响任务；手动快捷键和实时跟随只在手动控制页生效，急停在所有页面可用。

程序页的执行栏集中显示运行状态、程序名称、当前动作和已完成步数，不再重复显示全局横幅。运行、暂停、完成和出错分别用小图标及状态色区分；循环和条件不显示推算的固定百分比。运行时只显示暂停、停止和只读速度，暂停时显示继续、下一步、停止，结束后可再次运行。程序树进入只读执行视图，收起添加入口与编辑工具，在实际执行节点上显示「执行中」或「已暂停」。相同错误不会随快照反复通知。

运行程序的控制窗口断开，或控制心跳超过 2 秒未更新，程序停止。恢复连接后需重新启动。切到任务所属页面之外时，顶部显示与内容区对齐的紧凑任务提示，保留返回和停止入口；回到程序页或示教轨迹页后使用页面自身的状态与控制，避免重复提示。

## 示教轨迹工作区

「作业 → 示教轨迹」使用轨迹库、3D 预览与编辑、录制与执行三个区域。左侧始终列出已录制文件，录制中的文件显示红色标记、时长和帧数；搜索、重命名、复制与删除集中在库中。删除需要确认。程序引用轨迹文件名，重命名或删除后应更新程序中的引用。

两种动作输入方式使用同一个采样器，记录时间戳、关节位置/速度和夹爪：

- **手动拖臂**：开始录制时进入 Gravity 重力补偿，由操作者扶住并引导机械臂。进入手动控制后，关节角默认只读；仿真臂须显式勾选「启用仿真拖动」后，滑条才会改变仿真姿态。真机始终拒绝此类滑条拖动指令。
- **界面操控**：进入位置控制，通过手动控制页的关节或笛卡尔操作生成动作。换页不会终止录制。

红色录制按钮在「开始录制」与「停止并保存」之间切换。中间的蓝色 **3D 预览** 只更新浏览器内的 CAD 模型，不发送运动命令；支持播放/暂停、拖动进度、0.25–2× 速度、循环播放、末端路径和六关节角度曲线。点击曲线可定位，拖拽 3D 可旋转视角，滚轮缩放。

区间选择采用时间轴操作：在关节曲线上按住拖动框选；拖动蓝色选区两端手柄调整起止时间；拖动选区中间可整体平移。点击曲线或时间轴可定位播放头，点击「全选」选中全部。起止手柄和选区均支持方向键微调，Shift 加方向键加大步长；I / O 将当前播放位置设为起点 / 终点。「预览选区」只播放选中范围，开启循环后只循环该范围。需要精确数值时展开「精确设置起止时间」。

去静止、平滑、变速、重采样、反向始终只处理时间轴上的选区，不再另设「处理范围」开关。需要处理全部时先点击「全选」，按钮会显示「应用到全选轨迹」；按钮、范围提示及历史记录都会标出作用范围。变速和去静止改变选中片段的长度，后续采样仅整体移动时间，选区外关节与夹爪位置保持原样。局部反向在与前后片段的连接处添加可设时长的过渡段，避免反转端点造成位置跳变。「合并」始终追加到整条轨迹末尾。此前保存的无范围信息的操作历史仍按当时的全轨迹语义恢复，并标为「整条轨迹」。

编辑按操作历史形成草稿，支持撤销、重做；每次操作后先预览，再「保存为新轨迹」，原文件保留。选区调整也进入历史：一次拖动、一次精确时间输入、一次全选或标记起终点各记一步；连续方向键调整在松开按键时记一步。Ctrl / Cmd + Z 撤销，Ctrl / Cmd + Shift + Z 或 Ctrl / Cmd + Y 重做（输入框内保留文字编辑快捷键）。「编辑历史」始终显示原始录制、已应用及已撤销步骤，可以点击任意步骤同时恢复轨迹数据与选区，也可恢复到已保存版本。保存后、刷新页面后或重新打开文件后，历史仍然可用；撤销不再只限于当前草稿。单纯调整选区不会修改采样，也不阻止执行已保存的整条文件。支持：

| 编辑 | 行为 |
| --- | --- |
| 保留区间 | 输入起止秒数或从当前播放位置设定边界，插值保留边界并从零计时。 |
| 删除区间 | 删除指定时间段；中间切除时使用 1 秒过渡连接两端，避免位置跳变。 |
| 去除静止 | 按累计关节位移及夹爪位移识别停顿，角度阈值、最短静止时长可调；夹爪动作不会当成停顿删除。 |
| 轨迹平滑 | 使用 3–101 帧移动平均处理关节角，保留原始起点、终点及夹爪动作。 |
| 变速 | 以 0.1–2× 调整处理范围的时间轴，并重新计算速度；后续片段整体移动。 |
| 重采样 | 对处理范围做 10–100 Hz 插值，保持区间精确终点与总时长，选区外采样不变。 |
| 反向 | 反转处理范围内的关节和夹爪动作；局部反向与前后片段通过过渡连接。 |
| 合并 | 选择另一文件追加在末尾，过渡时长 0.2–30 秒，使用五次插值连接两端。 |

「继续录制轨迹」使用录制加号图标，复制原轨迹并追加新采样，保存成新的完整文件。关节与夹爪必须已在末点附近（误差不超过 3°），否则按钮禁用且后端拒绝开始。带机械臂图标的「按住移动到末点」以 10°/s 移动关节：按住鼠标、触摸或空格 / 回车时运行，松开、移出按钮、取消触摸、切页或窗口失焦时停止。关节到位（误差不超过 0.25°）后移动按钮禁用；夹爪需在手动控制页对齐。续录可使用任一动作输入方式。

按住移动具有独立的控制会话与服务端截止时间：浏览器每 100 ms 续期，超过 350 ms 未续期或所属连接断开就停止，即使仍有其他窗口连接也不继续运行。普通心跳不能续期；旧会话的停止消息不能中断新的按住会话或其他手动运动。旧服务不支持此协议时，界面禁用按住移动并提示重启服务。

绿色 **机械臂执行** 使用所选已保存文件，先以 5–30°/s 走到起点，再以 0.5–1× 回放；草稿需先保存。停止执行会保持当前位置。屏幕预览倍率和机械臂执行倍率独立，屏幕循环也不会使机械臂循环执行。轨迹编辑和 3D 预览不包含环境碰撞检测或动力学可行性认证，实机仍需低速验证。

录制期间控制模式及重力模型被锁定，须先停止录制才能切换。拖臂模式禁用发送位置、实时跟随、复位及夹爪位置控制。切换页面不会启动位置保持写者，也不会自动开启仿真拖动；软件录制仍可正常发送位置。停止拖臂录制时，只有位置模式恢复成功才会显示 Position。

仿真复位与真机采用相同的定时关节路径，结束时更新保持目标。复位后再次发送位置仍按界面速度插值，不能复用复位前的旧目标。发送前先检查目标，不预先发送保持指令；静止且已在目标位置时只提示「已在目标位置，无需移动」，不会产生运动。位置判断优先采用实测关节反馈。保持时也会检查旧伺服目标是否已偏离反馈，避免跳回旧姿态。路径执行期间状态会持续显示运动中，避免仿真瞬时速度为零时误判完成。

手动「发送位置」采用最新目标优先：新目标替换尚未完成的手动移动或复位，从当前姿态按设定速度重新规划，不必等旧目标到位，不直接跳到新位置。已积累的键盘增量会被清理；断线期间只保留最新的手动位置或复位目标，仍受原有排队超时约束。程序与示教轨迹保持顺序执行，程序运行或暂停时继续禁止手动覆盖。

「导出 JSONL」导出已保存文件的全部采样。长轨迹的浏览器预览最多约 3000 帧；编辑、保存、回放和导出使用完整数据。每条轨迹最多处理 360000 帧，每份轨迹最多保留 200 步编辑历史。旧 Windows 录制的重复时间戳保留最后一帧，新录制使用高精度计时并保持时间递增。

历史使用录制目录内 `workspace/trajectory_history/` 中的不可变源快照；合并来源也会保存快照。重命名或删除原录制、合并来源不会破坏已保存的历史。搬迁完整历史时应连同此目录复制。单独导出的 JSONL 仍包含完整的当前轨迹，可独立回放；若没有对应快照，编辑器会提示此前历史无法恢复，并以该文件的当前数据开始新的编辑历史。

## 数据与开发

路点及程序保存在录制数据目录的 `workspace/` 下：`waypoints.json` 和 `programs/*.json`。便携包更新沿用录制数据保留规则，开发构建不把这些用户数据打包。`STATION_RECORDINGS_DIR` 可指定数据根目录。

前端 `workbench.js` / `workbench.css` 管理程序与路点，`trajectories.js` / `trajectories.css` 管理轨迹，均复用现有 WebSocket。`trajectory_workspace.py` 负责完整分辨率编辑和有界预览。轨迹编辑通过 `workbench` 通道的 `traj_*` 操作传输源文件与操作历史，不把完整轨迹反复从浏览器上传，也兼容仅支持 HTTP GET 的旧 websockets 版本。浏览器会验证编辑服务版本；旧服务无法保证选区语义时，编辑入口禁用并提示重启站控，避免静默执行全轨迹处理。仅刷新网页不会更新已运行的运动服务。`programs.py` 负责验证、脚本转换、存储和程序状态；执行器由运动进程的 tick 推进。站控适配层继承子模块 SDK，SDK 源码或当前解释器的原生扩展变化会更新启动版本指纹；`trajectory_workspace.py` 和 `traj.py` 同样纳入指纹检查。

`arm3d.js` 在首次显示 3D 时才创建一个 WebGL 渲染器；手动控制、程序和示教轨迹共用它与同一个画布。CAD 网格、法线、夹爪拆分结果和材质在窗口内只加载、解析一次，并共用 GPU 缓冲。实时视图与轨迹预览分别保留关节姿态、夹爪、相机和路径；切页只切换画布所属视图，不让实时反馈覆盖离线预览。隐藏视图只缓存最新数据，恢复显示后再计算关节和路径；静止时不调度绘制，运动或交互时按需绘制，上限 30 FPS，窗口隐藏时停止绘制。显示帧率与原有运动控制、反馈频率独立。轨迹曲线缓存底图，播放时只重画进度线，编辑区间、轨迹数据或尺寸改变时才重建曲线。

完整界面状态包在跟随期间仍以最高 10 Hz 更新，避免实时 RPY、实测角度和程序状态冻结；拥堵时合并位置帧会保留尚未发送的完整状态。此频率只用于界面，运动循环默认 100 Hz，真机 servo 写入也配置为 100 Hz，高频二进制位置通道独立保留。配置频率不等同于实测调度频率。手动发送的到位判断同时核对实测反馈与当前显示位置，并要求机械臂静止，避免旧反馈误拦截新目标。「实测角度」表优先显示电机反馈，旧服务缺少反馈字段时回退至位置数据。
