# FAFU 机械臂站控 · 客户使用说明

本文面向**现场操作员**。打开软件目录里的 `README.md` 就是这份说明。

本软件在**本机 Windows** 上运行，用 USB 直连机械臂调试板。打开后就是机械臂控制页：3D 参考臂、关节/笛卡尔、作业相机、急停、示教与回放。

---

## 1. 您收到的是什么

请把整个 **`FAFUArmStation` 文件夹**拷到客户电脑（可先打成 zip 再解压）。不要只拷里面的某一个 exe。

| 文件 / 文件夹 | 作用 |
|---------------|------|
| `FAFUArmStation.exe` | 日常启动（推荐） |
| `启动真机.bat` | 同样启动真机控制（效果与 exe 相同） |
| `Install.bat` / `Uninstall.bat` | 安装到用户目录 / 卸载 |
| `app\urdf\` | 重力补偿用的机械臂模型（`.urdf`） |
| `app\docs\` | 更细的技术说明（一般不必看） |
| `runtime\` | 软件自带的运行环境，**不要删、不要改系统 PATH** |

**不必**在客户电脑上安装 Python，也**不要**勾选「Add Python to PATH」。

第一次双击 `FAFUArmStation.exe` 时，软件会复制到本用户目录：

`C:\Users\<您的用户名>\AppData\Local\FAFUArmStation`

同时在桌面建立快捷方式 **FAFUArmStation**。以后点桌面图标即可。更新时：用新的整个文件夹覆盖旧包后再双击 exe，会覆盖用户目录里的副本。

卸载：运行安装目录中的 `Uninstall.bat`，或删除上述用户目录和桌面快捷方式。

## 2. 电脑与接线

| 项目 | 要求 |
|------|------|
| 系统 | Windows 10 / 11，64 位 |
| 机械臂 | USB 线插到**运行本软件的这台电脑** |
| 作业相机 | USB 插到同一台电脑。交付相机是 Intel RealSense D405。软件不会用笔记本盖上的内置摄像头 |
| 窗口 | 系统自带 Edge / WebView2（Win10/11 一般已有） |

建议：USB-C 笔记本用可靠转接；启动前先插好机械臂 USB。

## 3. 第一次开机（建议按这个顺序）

1. **清场**：工作空间内无障碍、周围无人。手臂下方不要伸手去托。
2. **接线**：机械臂 USB（以及作业相机，如有）插到本机。
3. **启动**：双击 `FAFUArmStation.exe`，或桌面快捷方式。
4. **看顶栏**：应出现连接状态。USB 已插好时，软件会自动 Connect 并使能；电机保持**当前姿态**，不会自己甩臂。
5. **先小动**：Speed 调到 20–30 deg/s，在 **Position** 下拖一个关节，点「发送位置」，确认方向正确。
6. **结束**：关窗口即可。需要卸力时再点「去使能」。不要在手臂悬空、无人扶着时去使能。

无真机时：右侧 **臂源** 点「仿真臂」，可练界面和轨迹，网页动作不会传到真机。

## 4. 界面怎么看

页面分成三列，顶栏是状态和急停。上方一排开关可单独隐藏「关节 / 3D / 相机 / 连接 / 末端 / 路点 / 示教 / 键盘」。

### 4.1 顶栏

| 项目 | 含义 |
|------|------|
| 连接指示 | 机械臂 USB（或仿真）是否在线。**不是**网页是否打开。没插真机时应为「未连接」，不要当成已连上真机 |
| 指令 Hz / RTT | 控制频率和往返时延。真机正常时 Hz 应接近 100 |
| 安全 | 是否处于急停锁存 |
| 假臂 · 假相机 | 当前是否在仿真/假数据。识别到 RealSense 后显示「真相机」 |
| **急停 ESTOP** | 立刻刹车。快捷键 `Esc` |
| **解除急停** | 解除软件锁存。快捷键 `U` |

急停后会出现黄色横幅。请先读第 11 节再继续操作。

### 4.2 中间：3D 参考臂与作业相机

- **3D 参考臂**：跟着真实（或仿真）关节转。左键拖旋转，滚轮缩放，**双击**重新框选进视口。夹爪开合有行程，不是瞬间跳开。
- **作业相机**：启动时自动认 USB，优先 RealSense D405，跳过笔记本内置摄像头。没插相机时是假彩条，属正常。
- 若一直是假画面：Windows「设置 → 隐私和安全性 → 相机」里允许**桌面应用**访问相机，并确认 D405 已插上。

## 5. 连接、使能、臂源

右侧 **Robot Connection** 显示当前后端、链路、是否使能、夹爪和控制模式。

### 5.1 臂源

| 按钮 | 作用 |
|------|------|
| **真机 USB** | 控制实物机械臂 |
| **仿真臂** | 只练界面，不动真机 |

切换**不必重启**软件。

**注意：**

- 切到「仿真臂」再切回「真机 USB」**不会自动使能**，必须再点「使能」。
- 启动后才插 USB：请点 **Connect**，再点 **使能**（或关窗口再开一次）。
- 仿真时网页上怎么拖都不会传到真机。切回真机前，再看一眼臂源是否为「真机 USB」、使能是否已亮。

### 5.2 Connect / 使能

| 按钮 | 作用 |
|------|------|
| **Connect** | 打开 USB 串口，读状态。当前态会亮起；按下到应答前显示「正在连接…」 |
| **Disconnect** | 断开串口 |
| **使能** | 电机上电保持。快捷键 `P` |
| **去使能** | 卸力。快捷键 `L`。手臂可能下垂，先扶稳或落到安全姿态 |

**电机状态**表：使能后看各轴是否在线、有无故障、当前模式。

**缺轴也能用：** 交付时可以不装夹爪或个别电机。顶部可能显示「部分轴离线」。在线轴仍可 Connect、使能、用关节/键盘控制。夹爪按钮会提示离线，其余轴照常。

**不能做的：**

- **J1–J6 有轴离线时，不要进 Gravity / Gra+Fri / Impedance**（按钮会不可用）。请用 Position 控制在线轴。
- 不要在「实时跟随」或回放过程中乱点使能/去使能。
- 不要用其它官方工具同时占用同一 COM 口。

## 6. 控制模式（CONTROL MODE）

右侧四档，一次只生效一种。真机与仿真含义不同。

| 模式 | 真机在做什么 | 仿真在做什么 | 适合 |
|------|--------------|--------------|------|
| **Position** | 按目标角度走位置（发送位置、跟随、键盘、回放、路点） | 滑条 + 插补 | 日常点位、回放、路点 |
| **Gravity** | 重力补偿：手臂接近失重，可徒手拖。切入约 0.5 秒会刹一下速度，稳定后保持纯重力补偿 | 用滑条改当前角（**不是**真的力矩环） | 拖臂示教 |
| **Gra+Fri** | 与 Gravity 相同，另加摩擦补偿，拖起来更跟手 | 同 Gravity | 需要更顺的拖臂 |
| **Impedance** | 柔顺**保持进入时的姿态**，不会跟着你拖走 | 较慢位置跟随 | 需要软一点的保持 |

重力模型在右侧 **重力 URDF** 下拉框选择，与当前实物一致即可（常见 `fafu_baseV1` / `fafu_baseV2` 等）。拖臂录制也用当前选中的文件。换 URDF 时若已在浮空，软件会停环、重载再开环。

**注意：**

- 进 Gravity / Gra+Fri 前先**扶稳手臂**。切入时有短暂阻尼是正常的，之后应能轻松拖动。
- Gravity **没有**位置保持：松手后手臂靠重力补偿漂着，不是锁死。不要松手走开。
- Impedance **不是**拖动示教，不要用它来录轨迹。
- 仿真里这三档只是方便练界面，手感与真机不同。
- 切回 Position 后才会重新位置保持。回放、路点、复位都要求在 Position。

## 7. 关节空间、笛卡尔、速度、发送、复位

左侧 **Joints**。

### 7.1 关节空间（快捷键 `J`）

1. 拖 J1–J6 滑条，只改**目标**，手臂还不动。
2. 点 **发送位置**（或按 `Enter`），手臂按 Speed 走到目标。
3. 需要边拖边动：先勾选 **实时跟随**（不会因为拖滑条而自动勾上）。快捷键 `F`。

**注意：**

- 未勾选跟随时，拖滑条**不会**动臂。这是保护，防止误碰。
- 跟随开启后，速度仍受 Speed（deg/s）限制，不会一拍甩到目标。
- 跟随是连续伺服。周围必须清空；结束时先取消勾选。

### 7.2 笛卡尔（快捷键 `T`）

控制末端位置 X/Y/Z 和姿态（滚转 / 俯仰 / 偏航）。

- 拖滑条只改目标；**松手**或点「发送位置」后，软件算关节角再按 Speed 走过去。
- 键盘才是边按边动，见第 8 节。
- 零位附近可能算不出解（奇异）。无解时先把 J2/J3 略抬起来再试。

### 7.3 Speed

范围约 5–80 deg/s。作用于：发送位置、实时跟随、键盘、路点插补。

**第一次务必偏低。** 回放另有自己的倍率（0.5–1.0），见第 10 节。

### 7.4 复位（按钮或 `H`）

从**当前姿态**受控回到零位：沿路点连续走，中间不停顿。只在直线会碰到桌面时略抬肘，不会故意往上伸直扫到上方障碍。

**注意：** 复位前看清上方和桌面。急停后也可以复位（受控回零）；其它运动要先解除急停。

## 8. 键盘遥操作

在 **Position** 下，焦点不在输入框时：

| 按键 | 动作 |
|------|------|
| `W` / `S` | 末端 X 前后 |
| `A` / `D` | 末端 Y 左右 |
| `Q` / `E` | 末端 Z 上下 |
| `1` / `2` | 滚转 |
| `3` / `4` | 俯仰 |
| `5` / `6` | 偏航 |
| `空格` | 夹爪开 / 合（按当前状态切换） |

笛卡尔键是**按住连续动**。输入框里打字时，除 `Esc` 外快捷键一般不触发。顶栏「快捷键」可展开完整列表。

## 9. 夹爪

左侧夹爪滑条是角度（约 8–75°），另有**夹持力矩**。

| 操作 | 说明 |
|------|------|
| **打开 / 闭合** | 按当前力矩上限去开合 |
| 角度滑条 | 指定开合角度 |
| 夹持力矩 | 默认约 300（约 1.6 Nm）。易碎物建议降到 80–120 |
| `空格` | 开/合切换 |

夹爪没装或离线时，关节仍可控制；夹爪按钮会提示离线，回放时夹爪指令会跳过，不会整条轨迹失败。

## 10. 路点 与 示教轨迹（不是一回事）

### 10.1 路点（WAYPOINTS）——稀疏几个点

适合：抓取示教里「记 3～8 个关键姿态，再按顺序走一遍」。

1. 把臂摆到要记的姿态（发送位置、键盘或拖臂后切回 Position）。
2. 点 **+ 记录当前**。
3. 可改每点时长。
4. 在 **Position** 下点 **运行轨迹**。软件在点与点之间插补。
5. **清空**只清页面上的路点列表，不删磁盘上的示教文件。

**不要**用「运行轨迹」去还原拖臂时的连续时序。那是下一节的「回放」。

### 10.2 示教轨迹 —— 连续录、按时间回放

软件按约 100 Hz 把整条曲线写到磁盘，和路点不是同一套数据。

**两种录法：**

| 方式 | 怎么用 | 注意 |
|------|--------|------|
| **拖臂录制**（默认） | 点「开始录制」会切入 **Gravity**（纯重力，不加摩擦）。先扶稳，再徒手拖。点「停止录制」后回到 Position 保持 | 真机才有失重手感。仿真只能用滑条代替拖臂 |
| **软件录制** | 留在 Position，用跟随或键盘边动边录 | 适合不方便徒手拖的场合 |

操作步骤：

1. 选「拖臂录制」或「软件录制」。
2. 点 **开始录制**，页面显示帧数。
3. 点 **停止录制**。文件出现在本机 recordings 目录（见第 13 节）。
4. 在列表里选文件，调 **回放倍率**（0.5–1.0），点 **回放**。
5. 手臂会先**慢速走到轨迹起点并停稳**，再按录制时的时间往下走。这不是瞬间瞬移。
6. **重命名**：只改本机该文件的名字，可用中文，可省略 `.jsonl`。
7. **删除文件**：只删列表里选中的那一条，不可恢复。

**注意：**

- 回放必须在 **Position**。若还在 Gravity，软件会先切回位置保持。
- 急停会**立刻停止**录制或回放；已写下的文件会保留。
- 解除急停后再回放 / 复位：从**当前实际角度**走，不应先猛冲回急停那一瞬间的旧目标。
- 不要在回放中途切仿真/真机或去使能。
- 倍率不要一上来就 1.0；现场建议先 0.5 看一遍。

## 11. 急停

| 动作 | 结果 |
|------|------|
| 点 **急停 ESTOP** 或按 `Esc` | 软件锁存；电机切入**刹车**（短路阻尼） |
| 点 **解除急停** 或按 `U` | 解除锁存，从当前实测角继续 |

刹车**不是**断电，也**没有**位置保持力矩。抬着、伸出去的手臂**可能下沉**。现场请按住或让它落到安全位置。

急停后仍可点「复位」受控回零。发送位置、跟随、回放、路点等其它运动，必须先解除急停。

刹车后再使能，有时要等几秒，属正常，**不是**软件死了。若顶栏很久完全无刷新，再看第 15 节。

拔掉 USB 也可立即断开通信。这是硬件侧的最后手段。

## 13. 文件放在哪

日常请走桌面快捷方式。数据和模型在本机这些位置：

| 内容 | 路径 |
|------|------|
| 软件安装副本 | `%LOCALAPPDATA%\FAFUArmStation\` （资源管理器地址栏可直接粘贴） |
| **示教轨迹**（录制生成） | `%LOCALAPPDATA%\FAFUArmStation\recordings\` ，文件名类似 `traj_20260327_153012.jsonl` |
| **重力 URDF**（安装后） | `%LOCALAPPDATA%\FAFUArmStation\app\urdf\` |
| 您解压的原包里的 URDF | `FAFUArmStation\app\urdf\` |
| 桌面启动日志 | `%TEMP%\fafu-station-app.log` |

自己标定的 6 轴 URDF：把 `.urdf` 拷进 **`app\urdf\`**（安装目录与更新用的原包都放一份更稳），重启软件后即可在「重力 URDF」下拉框里选。不要用名字带 `_kin` 的文件做重力（那是运动学用的）。

轨迹不要用手改 jsonl，除非您明确知道格式。换电脑时：把 `recordings` 文件夹一并拷走即可。

## 14. 安全须知（请务必阅读）

1. 使能前清空工作空间，确认周围无人、桌上无易碎物。
2. 急停是刹车，手臂可能下沉；不要用身体去挡运动中的臂。
3. 首次真机、换场地、换负载：Speed 先低，先关节小幅运动。
4. Gravity / 拖臂时必须有人看着。松手不等于锁死。
5. 不要在跟随、回放、SERVO 过程中强行切换使能，或同时打开其它占用串口的程序。
6. 仿真能练会界面，**不能**代替真机安全检查。切回真机前确认臂源和使能。
7. 夹爪力矩按工件调节；夹持人、头发、线缆时立刻急停。
8. 本软件急停是站控锁存，不能替代现场硬件急停按钮（如有）。有硬件急停时优先拍硬件。

## 15. 常见问题

### 页面开了，真臂不动

- 右侧臂源是否停在「仿真臂」→ 切到「真机 USB」再点「使能」。
- 是否刚从仿真切回来（不会自动使能）。
- USB 是否在启动之后才插上 → Connect + 使能，或重启软件。
- 顶部是否提示未允许真机串口 → 请用 `FAFUArmStation.exe` 或 `启动真机.bat`，不要用只开仿真的方式启动。

### 顶栏显示「未连接」，但窗口是开着的

「连接」指机械臂链路，不是窗口。检查 USB、其它程序是否占用 COM 口、调试板供电。设备管理器里应能看到对应串口。

### 部分电机离线

夹爪或个别轴没装时可以继续用在线轴。不要整臂放弃。缺的是臂关节（J1–J6）时，不要进重力三档。

### 进不了 Gravity

J1–J6 必须全部在线。夹爪可以不在。先看电机状态表。仿真里 Gravity 只是滑条示教。

### 解除急停后提示「运动进程无应答」

刹车后再使能可能要数秒。请等顶栏 Hz 恢复，不要连点。若超过约 10 秒仍完全无刷新：关窗口再开（真机运动进程通常还在，会重新连上页面）。仍不行再重启软件。不要在手臂还在动时强行结束进程。

### 回放或复位时先猛冲到一个旧位置

正常应当从**当前实际角度**出发。若仍出现猛冲：先急停，扶稳，解除急停，确认已在 Position，再复位或回放。并把现象告知交付人员（附大约时间，便于查日志）。

### 相机一直是假彩条

确认插的是作业相机 D405，不是笔记本摄像头；在系统隐私设置里允许桌面应用使用相机。

### 独立窗口打不开

确认整包完整（含 `runtime` 与 `app`）。查看 `%TEMP%\fafu-station-app.log`。系统需有 WebView2。也可在本机浏览器打开 `http://127.0.0.1:9400/`（须已有一份站控在运行）。

### 9400 端口被占用 / 重复启动

站控已在运行时，再开窗口会复用，**不会**再杀一份机械臂进程。直接用已打开的窗口即可。需要整站重启时，确认手臂已停下再关干净后重开。

### 想换重力模型或加自己的 URDF

见第 13 节：文件放入 `app\urdf\`，在页面下拉框选择。换模型后若正在浮空，等它重新加载完成再拖臂。
