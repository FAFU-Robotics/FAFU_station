Noto Sans SC UI font

Source: https://github.com/google/fonts/tree/main/ofl/notosanssc
Upstream file: NotoSansSC[wght].ttf
License: SIL Open Font License 1.1, included in OFL-NotoSansSC.txt.

NotoSansSC-UI.woff2 is a local webfont, retaining variable weights 400-700.
It contains Latin, punctuation, symbols, CJK radicals, CJK Extension A,
the CJK Unified Ideographs block, and full-width forms. Other characters
fall back to the system Chinese UI font. No external font server is used.

Built using fontTools: subset Unicode ranges U+0000-024F, U+2000-27FF,
U+2E80-9FFF, U+FF00-FFEF; retain all layout features and naming records;
then restrict the wght axis to 400-700 and encode as WOFF2.
