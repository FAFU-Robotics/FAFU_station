      两种输入方式有什么区别？

      两者都按时间记录关节角、速度和夹爪。手动拖臂会启用重力补偿，由你扶住并拖动机械臂；界面操控使用位置控制，通过关节滑条或笛卡尔操作生成动作。仿真臂通过滑条示教。

      录制会跨页面继续，顶部状态栏可随时停止。

      继续录制

      先移动机械臂到轨迹末点，再录制后续动作；结果另存为新轨迹。
