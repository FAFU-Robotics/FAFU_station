机械臂

布局参考 Panthera-HT Host。正中是 3D 参考臂（SDK CAD 网格，跟随后端关节）。作业相机一路，启动时自动识别本机 USB（优先 RealSense D405，跳过笔记本内置摄像头）。可用开关隐藏。mock / sim 可在本页控假臂；真机须两道闸：STATION_ALLOW_LIVE_ARM=1 且允许运动。

Joints

关节空间：拖 J1–J6 改目标，点「发送位置」下发；勾选「实时跟随」后拖滑条才发 servo。笛卡尔：拖末端滑条，松手或点「发送位置」后按 Speed 走到目标。
